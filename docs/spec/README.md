## デザイントークン

方針（デザインより）: 名刺そのものを主役に。紙の質感のオフホワイト地・墨色の文字・罫線で「名刺フォルダ」を表現し、色は 3 つの意味色だけに限定する。主要操作は親指の届く下部に集約する。

| 用途                       | 値                                                                              |
| -------------------------- | ------------------------------------------------------------------------------- |
| 背景（画面）               | `#F5F3EE`                                                                       |
| 面（カード・入力欄）       | `#FFFFFF`                                                                       |
| 文字（墨）・主ボタン背景   | `#1B1A17`                                                                       |
| 補助文字                   | `#6B675F`                                                                       |
| プレースホルダ・無効       | `#A8A397`                                                                       |
| 罫線                       | `#D8D3C8`（入力欄）/ `#E4E0D6`（カード）/ `#EEEAE1`（行間）                     |
| 淡い面（セグメント・注記） | `#EEEAE1`                                                                       |
| プロジェクト（赤）         | 文字 `#B3372B` / 背景 `#F8E3DF` / 枠 `#EBC7C1`                                  |
| グループ（青）             | 文字 `#2456A6` / 背景 `#DFE8F6` / 枠 `#C3D3EC`                                  |
| AI 要確認（黄）            | 文字 `#6B4700` / 背景 `#F6E7B9`、アクセント `#E9B949`                           |
| 撮影・ビューワ（暗い画面） | `#111110` / `#0E0E0D`                                                           |
| 本文フォント               | Zen Kaku Gothic New（見出し 900、本文 400〜700）※アプリでは Noto Sans JP を使う |
| 数字・英字（日付・件数等） | IBM Plex Mono                                                                   |

- 画面幅 390px（スマホ）基準。主ボタンは高さ 54px・角丸 14px、入力欄は高さ 48px・角丸 10px。
- ダイアログはボトムシート（上端角丸 24px、背景 `rgba(27,26,23,.45)`）。
