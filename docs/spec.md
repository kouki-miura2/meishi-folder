# Meishi-folder

An app for registering and organizing business cards using photos.

もらった名刺の写真を撮り、クラウドでその情報を管理する。  
名刺記載の項目、名刺をもらった場面（日付、場所、機会）、その他補足事項（関連プロジェクト、関連グループ、ハンドルネーム　等）を記録・整理・検索するツール。  
名刺ごとに公開範囲を設定できる。

認証:

- Googleでログイン

アクセス権:

- 当初は、全データを登録したユーザー本人のみ参照・追加・変更・削除可能
- 将来対応: ユーザー同士が相互認証すると、会社・団体どうし、会社・団体＋部署どうしを関連付けられる。関連付け後は、公開範囲が「会社」「部署」の名刺をお互いに参照できる

データ構成:

- ユーザー: 会社または団体に所属する（複数可）
- 名刺: 1枚の名刺
- 関連プロジェクト・関連グループ: ユーザーごとのマスタ（GitHubのトピックのイメージ）。他ユーザーとは共有しない
- 会社・団体、部署: ユーザーごとのマスタ。他ユーザーとは共有しない
  - 将来対応: 自分のマスタと他ユーザーのマスタをメンテナンスして統合できる

会社・団体:

- 会社・団体名

部署:

- 会社・団体(選択)
- 部署名

ユーザー項目:

- 氏名(1)、氏名カナ(0..1)、会社・団体名(0..N・選択)、部署(0..N・選択)※会社・団体ごと

名刺:

- 名刺写真(0..2)　※表・裏
- 記載項目
  - 氏名(0..1)、氏名カナ(0..1)、氏名ローマ字(0..1)、会社・団体名(0..1・マスタ参照)、所属(0..N・部署マスタ参照)、役職(0..N)、職種(0..N)
  - 携帯(0..1)
  - メール(0..N)
  - その他連絡(0..N)
  - URL(0..1)
  - 事業所(0..N)
    - 郵便番号(0..1)
    - 住所(0..1)
    - 電話(0..1)
    - FAX(0..1)
- 場面
  - 取得日(0..1)、取得場所(0..1)、取得機会(0..1)
- 補足事項
  - 関連プロジェクト(0..N・マスタ選択)、関連グループ(0..N・マスタ選択)、ハンドルネーム(0..1)
- 公開範囲(個人、会社、部署)　※登録時は「個人」
- 登録ユーザー、登録日時、更新日時
- 氏名、氏名カナ、ハンドルネームのいずれか1つは必須とする

画面構成:

- ようこそ画面
  - 氏名、氏名カナ、会社・団体(選択)、部署(選択)を入力
- 名刺一覧画面
  - 名刺一覧　※並び順: 氏名カナ、無ければハンドルネーム、無ければ氏名
    - 会社・団体名
    - 所属
    - 氏名、氏名カナ or ハンドルネーム
    - 関連プロジェクト(chip)　※トピック赤
    - 関連グループ(chip)　※トピック青
  - フィルタダイアログ
    - 関連プロジェクト
    - 関連グループ
    - テキスト絞り込み　※全項目
  - 名刺登録ボタン
- 名刺詳細画面
  - 名刺写真(タップで画像ビューワ表示)　※表・裏で最大2枚
  - 全項目(名刺記載・場面・補足事項・公開範囲)
  - 参照・追加・変更・削除モード
- 会社・団体設定画面
  - 会社・団体マスタを追加・変更・削除
  - N件のマスタを統合※表記ゆれの解消目的
- 部署設定画面
  - 会社・団体設定画面のサブ画面
  - 部署マスタを追加・変更・削除
  - N件のマスタを統合※表記ゆれの解消目的

処理概要:

- 名刺登録
  - 流れ: 撮影／画像選択 → AI抽出 → 確認・訂正 → 保存
  - Cloudflare WorkersAI で名刺記載項目を抽出
    - Vision to Textができる以下のモデルを使用
    - https://developers.cloudflare.com/ai/models/%40cf/meta/llama-3.2-11b-vision-instruct/
  - 名刺記載項目を自動入力し、ユーザーが訂正してから保存できる
  - 会社・団体は一致するマスタを確認、あればマスタ参照、無ければ登録時に新規マスタ作成
  - 部署は一致するマスタを確認、あればマスタ参照、無ければ登録時に新規マスタ作成
    ※部署は会社・団体に属するサブマスタ（同じ名称でも会社・団体が異なれば異なる部署）
  - 登録済みの名刺と同一人物と判定された場合、候補を表示し、上書きするか新規登録するかをユーザーに確認する
    - 判定: 氏名の一致（同姓同名の可能性があるため、候補を見てユーザーが判断する）
    - 上書き対象: 名刺写真・名刺記載項目のみ。場面・補足事項は既存の値を保持する
- マスタ正規化（名寄せ）
  - 表記ゆれで同じ意味の会社・団体や部署のマスタが作られた場合、ユーザーが後から名寄せする
